# Reconstruction Classification Implementation Plan

**Goal:** Freeze an evidence-linked reconstruction register and the fastest compliant GitHub-native delivery sequence.

**Architecture:** Documentation-only classification. Preserve history; do not mutate product behavior or host state.

**Tools:** Git history/refs, GitHub PR/Actions evidence, KIS project/runtime inspection, VirtualBox/Windows read-only host inspection.

## Tasks

1. Enumerate post-boundary merged PRs and preserved open/frozen/local branches.
2. Compare each item to the restored baseline and classify retain/retire/future posture.
3. Record host/runtime residue and distinguish product state from optional installed software.
4. Audit the restored verification lifecycle and retain the exact-head GitHub Actions model if already optimal.
5. Freeze the serial child-change order and stale-PR handling rule.
6. Run governance check and required documentation/code-quality review; publish one exact head for GitHub Actions verification.

## Constraints

- No product implementation in this slice.
- No system-software uninstall.
- No permanent deletion; later generated-state cleanup uses quarantine.
- No merge queue for serial children unless concurrency requirements materially change.
